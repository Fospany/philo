# Philosophers 🍝

A clean and efficient simulation of the classic **Dining Philosophers Problem**, exploring the fundamentals of multithreading and process synchronization in C.

---

## 📘 Description

The goal of this project is to solve the famous concurrency problem designed by Edsger Dijkstra. A specific number of philosophers sit around a round table with a large bowl of spaghetti. There are as many forks on the table as there are philosophers. 

During the simulation, each philosopher must cycle through three states: **eating**, **sleeping**, and **thinking**. 
* To eat, a philosopher must pick up **two forks** (the one on their left and the one on their right).
* If a philosopher doesn't start eating within `time_to_die` milliseconds since their last meal (or the start of the simulation), they die of starvation.
* Philosophers do not communicate with each other and cannot inherently know if another is close to dying.

The objective is to implement a robust scheduling algorithm using **threads** and **mutexes** that manages shared resources (forks) efficiently, preventing **deadlocks** (where philosophers block each other indefinitely) and **data races** (simultaneous memory access resulting in corrupted data).

## 🛠️ Instructions

### Compilation
The project includes a standard `Makefile` that compiles the source files with the strict `-Wall -Wextra -Werror` flags. To compile the executable, run:

make

### Execution
Run the compiled binary with the following arguments:

./philo <number_of_philosophers> <time_to_die> <time_to_eat> <time_to_sleep> [number_of_times_each_philosopher_must_eat]

* **Arguments (all time values are in milliseconds):**
  * `number_of_philosophers`: The total number of philosophers and forks.
  * `time_to_die`: The maximum time a philosopher can survive without eating.
  * `time_to_eat`: The duration a philosopher takes to finish eating.
  * `time_to_sleep`: The duration a philosopher spends sleeping.
  * `[number_of_times_each_philosopher_must_eat]` *(Optional)*: If all philosophers eat at least this many times, the simulation stops cleanly. If omitted, the simulation runs until a philosopher dies.

### Execution Examples

# Baseline check: One philosopher should die quickly
./philo 1 800 200 200

# Normal run: No philosopher should die
./philo 4 410 200 200

# Strict limit: Simulation ends after everyone eats 7 times
./philo 5 800 200 200 7
